Deploy Si-JAPIRS ke Vercel

Website Anda menampilkan error 404 karena belum di-deploy. Ikuti langkah berikut:

Step 1: Klik Tombol Deploy

Klik tombol di bawah untuk mulai import project ke Vercel:

🚀 DEPLOY TO VERCEL

Step 2: Login atau Signup

Login dengan GitHub account Anda (JVsHARK31)

Step 3: Configure Environment Variables

Tambahkan SEMUA environment variables berikut:

NEXTAUTH_URL=https://si-japirs.vercel.app NEXTAUTH_SECRET=[copy dari .env.local] GOOGLE_CLIENT_ID=[copy dari .env.local] GOOGLE_CLIENT_SECRET=[copy dari .env.local] DATABASE_URL=[copy dari .env.local - update password] NEXT_PUBLIC_SUPABASE_URL=[copy dari .env.local] NEXT_PUBLIC_SUPABASE_ANON_KEY=[copy dari .env.local] SUPABASE_SERVICE_ROLE_KEY=[copy dari .env.local] GPT_API_KEY=[copy dari .env.local] GPT_API_URL=https://ai.sumopod.com/v1 GPT_MODEL=gpt-4.1-nano SCHOLAR_API_KEY=[copy dari .env.local] SCHOLAR_API_URL=https://serpapi.com/search FILE_MAX_MB=30

📁 Buka file C:\Users\HP\Downloads\Website Si-JAPIR\si-japir\.env.local untuk copy values

⚠️ PENTING:
  • Update DATABASE_URL dengan password Supabase yang benar
  • Generate NEXTAUTH_SECRET baru untuk production
  • Pastikan SEMUA variables di-add (jangan ada yang terlewat)

Step 4: Deploy

Klik tombol "Deploy" dan tunggu 2-3 menit

  • Repository sudah public di GitHub
  • Semua environment variables sudah di-add
  • DATABASE_URL password sudah benar
  • NEXTAUTH_URL = https://si-japirs.vercel.app
  • Build berhasil (green checkmark)
✅ Setelah Deploy Berhasil:

Website akan live di: https://si-japirs.vercel.app

Alternative: Deploy via CLI dengan vercel command
